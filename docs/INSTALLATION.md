# Installation

1. Install Python 3.10 or newer on Windows 10/11.
2. Create and activate a virtual environment.
3. Run `python -m pip install -r requirements.txt`.
4. Start the application with `python -m app.main`.

Without a Teensy, the UI starts and accurately displays **Not connected**.
Build an executable with `scripts\build.ps1` after installing PyInstaller.
